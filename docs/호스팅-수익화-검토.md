# 호스팅 · 수익화 검토 (2026-09-21)

> 새 채팅에서 이 논의를 이어가려고 남긴 기록입니다. 그때그때 바뀌는 정보(무료 티어,
> 광고 정책)가 많으니 **날짜를 보고, 중요한 건 다시 확인**하세요. 아래 내용은
> 2026-09-21에 실제로 찾아본 결과입니다.

## 배경 — 뭘 하려던 건가

전술판에 **스킨을 여러 개 만들고, 원하는 스킨은 광고(가능하면 보상형)를 봐야
풀리게** 해서 수익화하려 합니다. Streamlit이 이 목적에 맞는지, Reflex로 옮겨야
하는지가 질문이었습니다.

---

## 결론 세 줄

1. **지금은 옮기지 마세요.** 트래픽이 없어서 광고 수익이 0에 수렴합니다.
   (참고: ETF MANAGER 2027 카운터가 **누적** 5,171)
2. **"광고 보고 스킨 해금"은 프레임워크를 바꿔도 AdSense로는 안 됩니다.** 웹 리워드
   광고는 사실상 게임 전용입니다. 해금 조건을 광고가 아닌 다른 것으로 잡으세요.
3. 광고를 붙일 때의 최저 비용은 **월 5~6천원**(도메인 + 소형 VPS)입니다.
   그 밑으로 내리면 앱이 잠들어서 사용자가 20초씩 기다립니다.

## 1. 막히는 지점 두 개 (프레임워크와 무관)

### ① Streamlit Community Cloud는 상업적 이용 금지

> "You may not access or use the Community Cloud for the benefit of, or otherwise
> in connection with, **a business or commercial purpose**."

`myetfpaystub.streamlit.app`에 광고를 붙이면 약관 위반입니다. 기술적으로도,
**AdSense는 도메인 소유 확인을 요구**하는데 `streamlit.app`은 우리 것이 아니라
`ads.txt`를 올릴 수 없습니다.

→ **광고를 붙이려면 어떤 프레임워크를 쓰든 내 도메인 + 내 호스팅이 필요합니다.**

### ② 웹 리워드 광고는 게임 전용

AdSense의 리워드 광고는 **H5 Games Ads**로만 제공됩니다.

> "H5 game ad formats are **not enabled by default** – you must have **H5 games
> implemented on your website** to be eligible."

ETF 자산 관리 앱은 게임이 아니라 심사 통과가 어렵습니다. (모바일 네이티브 앱이면
AdMob 리워드가 깔끔하지만 그건 별개의 제품입니다.)

**대안 해금 조건**: 📸 캡처 이미지 공유, 일정 기간 사용, 후원, 또는 그냥 전부 무료로
풀고 배너로만 수익.

## 2. 우리 앱이 호스팅에 요구하는 조건

이게 후보를 확 좁힙니다.

| 조건 | 이유 |
|---|---|
| 상시 컨테이너 + WebSocket | Streamlit이 그렇게 동작 |
| **잠들면 안 됨** | 캐시가 프로세스 메모리에 있음. 깨어날 때마다 **TIGER 20초 콜드** |
| 내 도메인 | AdSense 필수 |
| 상업적 이용 허용 | 광고 = 상업적 이용 |

무료 티어들은 대개 **"잠들게 해서"** 무료입니다. 우리와 궁합이 나쁜 이유입니다.

> 💡 나중에 이사할 때 **캐시를 디스크/SQLite로 빼면** scale-to-zero 호스팅도
> 쓸 만해집니다(분배금은 12시간 캐시라 파일로 충분). `data/providers/cache.py`가
> 20줄이라 바꾸는 것도 금방입니다. 그러면 Cloud Run 무료 구간도 후보가 됩니다.

| 서비스 | 비용 | 내 도메인 | 실제 함정 |
|---|---|---|---|
| Streamlit Community Cloud | 무료 | ❌ | **상업적 이용 금지**, 12시간 무접속 시 잠듦, 1GB RAM |
| Hugging Face Spaces | 무료 (2vCPU/16GB) | ❌ Pro 전용 | 사양은 최고인데 도메인이 막혀 **AdSense 불가** |

| Render | 무료 | ✅ | 무접속 시 스핀다운 |

| **소형 VPS** (Hetzner·Contabo·카페24) | **월 3~6천원** | ✅ | 없음. 내가 관리 |
| Fly.io | 월 2~3천원 | ✅ | 무료 할당 없어짐, 대신 저렴 |

### 판을 뒤집는 카드 두 개

- **Cloudflare Tunnel (무료)** — 어디서 돌리든 **내 도메인 + HTTPS**를 공짜로 붙여줍니다.
  포트 개방 불필요. 도메인만 Cloudflare DNS에 올리면 됩니다. "커스텀 도메인 미지원"
  호스팅도 이걸로 우회됩니다. 집 PC도 가능(24시간 가동·전기료·보안·회선 약관은 감수).
- **광고 지면과 앱 서버 분리** — 랜딩/광고는 **Cloudflare Pages(무료·무제한)**,
  앱만 작은 서버에. AdSense가 내 정적 페이지에 붙어 정책도 깨끗하고 앱 서버는
  최소 사양이면 됩니다.

## 4. Reflex 평가

프레임워크만 보면 이 목적엔 Reflex가 Streamlit보다 낫습니다.

| | Streamlit | Reflex |
|---|---|---|
| 프론트엔드 | 못 건드림(샌드박스 iframe) | Next.js/React로 컴파일 — **`<head>` 우리 것** |
| 광고 스크립트 | 사실상 불가 | 가능 |
| 커스텀 도메인 | 무료 티어 불가 | 가능 |
| 상태 갱신 | 매번 스크립트 전체 재실행 | 이벤트 단위 |
| 비용 | 무료(비상업) | Hobby 크레딧제 / Pro $50월 / **자체 호스팅 무료** |

**그래도 지금은 아닙니다.** 이유:

1. 트래픽이 없어 수익이 0 → 리라이트 비용을 정당화 못 함
2. 진짜 병목은 프레임워크가 아니라 **호스팅/도메인**
3. **우리 자산 대부분이 이미 프레임워크 중립** — 전술판(`football_pitch`)도
   브라우저 저장(`local_store`)도 순수 HTML/JS, `services/`는 UI를 전혀 모름.
   다시 짜야 할 건 사실상 **`app.py` 하나**입니다.

## 5. 권장 순서

| 시점 | 할 일 |
|---|---|
| **지금** | 스킨 시스템을 **데이터로** 설계(프레임워크 중립). 이사해도 그대로 따라감 |
| **배포** | Streamlit Community Cloud. **광고는 붙이지 않음.** 사람부터 모음 |
| **DAU 300~500** | 내 도메인 + 소형 VPS로 이사. 이때 두 갈래: ① Streamlit 유지 + 내 랜딩 페이지에 iframe 임베드(리라이트 0) ② `app.py`만 Reflex/FastAPI로 재작성 |

비용 예상:

```
도메인      .com 약 1.5만원/년   ≈ 월 1,250원
VPS        1GB RAM 최소 사양    ≈ 월 4,000원
Cloudflare  무료 (TLS·CDN·DDoS)      0원
──────────────────────────────────────────
                        합계 월 5~6천원
```

## 6. 수익화 방식에 대한 의견

**증권사 계좌개설 제휴(CPA)** 는 배너 광고보다 수익이 수십 배이고, 우리 앱엔 이미
"어디에 가지고 있나요?" 화면이 있어 붙이기도 쉽습니다.

**그런데 권하지 않습니다.** 이 앱의 설계 전체가 *"데이터를 지어내지 않는다 / 모르면
모른다고 한다"* 는 신뢰 위에 서 있습니다. 제휴가 붙으면 "이 증권사를 왜 위에
보여주지?" 라는 질문이 생기고, 그게 CLAUDE.md 첫 줄과 정면으로 부딪힙니다.
배너 광고는 "이건 광고"라고 분리되지만 제휴는 화면 안에 섞입니다.

**스킨은 그런 충돌이 없어서 좋은 선택입니다** — 서비스의 정직성과 무관한 곳에서
돈을 버는 구조입니다.
