# ETF MANAGER 2027 — 작업 규칙

배당(분배금) 포트폴리오를 축구 전술판 위에서 짜고 백테스트하는 **한국어 Streamlit 앱**.
실서비스: https://etfmanager2027.streamlit.app · 저장소: rlagustn92/ETF-MANAGER-2027

> 자세한 구조·함정은 **HANDOVER.md** 에 있습니다. 코드를 깊게 건드리기 전에 그 문서의
> "8. 반드시 알아야 할 함정들" 을 먼저 읽으세요. 이 파일은 매 세션 지켜야 할 규칙만 담습니다.

## 대원칙 — 금융의 벽을 넘겨주는 엘리베이터

이 서비스의 존재 이유입니다. 기능을 더할지 말지, 문구를 어떻게 쓸지 헷갈리면 여기로 돌아옵니다.

**보는 사람은 금융 초보라고 가정합니다.** 배당락일이 뭔지, 수정주가가 뭔지 모르는 사람이
아무 설명 없이 들어와서, 배우지 않고도 자기 포트폴리오를 짜고 "한 달에 얼마 들어오는지"
를 알고 나가야 합니다. 금융은 계단이 너무 높아서 대부분 올라가다 포기합니다.
이 앱은 그 벽을 **엘리베이터로 넘겨주는** 도구입니다. 사용자를 공부시키지 않습니다.

그래서 이렇게 씁니다.

- **전문용어를 쓰지 않습니다.** "TTM", "배당수익률", "MDD" 대신 "최근 12개월",
  "투자금 대비 분배율", "도중 최대낙폭 — 고점 대비 얼마나 빠졌나" 처럼 풀어씁니다.
  꼭 써야 하면 옆에 괄호로 뜻을 답니다.
- **숫자 하나에 그게 무슨 뜻인지 한 줄을 붙입니다.** "최종 자산 ₩243,663,184" 만 두지 않고
  무엇이 합쳐진 값인지 바로 아래 쪼개서 보여줍니다.
- **다음에 뭘 눌러야 하는지 화면이 말해줍니다.** 빈 화면에 "예시로 시작해보세요" 가 있고,
  막히면 "버튼 한 번으로 날짜 고치기" 처럼 해결까지 이어집니다.
- **겁주지 않습니다.** 경고는 필요한 만큼만, 무슨 뜻이고 어떻게 하면 되는지까지 씁니다.
- 어려운 건 **앱이 대신 합니다.** 정수 주식 수, 환전, 분할 반영은 사용자가 몰라도 되게 합니다.

새 기능을 만들 때 자문할 것: **"금융 모르는 사람이 이 화면만 보고 이해할까?"**
아니라면 기능이 아니라 문구가 잘못된 것입니다.

## 절대 규칙

1. **데이터를 지어내지 않는다.** 값이 없으면 "데이터 없음" 이라고 화면에 적습니다.
   추정치를 슬쩍 끼워 넣지 않고, 추정이면 추정이라고 밝히고 근거를 같이 보여줍니다.
   "확인 못 함" 과 "문제 없음" 은 다른 말이며, 화면 문구에서도 구분해야 합니다.
2. **로컬에서만 테스트한다.** 실서비스 배포본은 건드리지 않습니다.
3. **배포는 사용자가 직접 한다.** 커밋까지는 도와도 push 는 사용자가 누릅니다.
   요청받지 않았으면 커밋도 하지 않습니다.
4. 화면 문구는 **투자 지식이 없는 사람이 읽는다고 보고** 씁니다. 전문용어 대신 풀어쓰고,
   금액은 `won()` / `won_short()` 를 통해 원화로 보여줍니다.

## 실행과 테스트

```bash
python -m pytest -q          # 전체 (네트워크 테스트는 자동 제외)
python -m pytest -m network  # 네트워크 포함 (실제 시세 조회)
streamlit run app.py         # 로컬 실행 (기본 8501)
```

기능을 하나 만들 때마다 테스트도 같이 만들고 돌립니다. 몰아서 하지 않습니다.
**항상 건너뛰는(skip) 테스트는 아무것도 검증하지 않습니다** — 조건을 고쳐서 실제로 돌게 만듭니다.

## 꼭 알아야 할 함정

- **`app.py` 만 핫리로드됩니다.** `services/`, `components/`, `config.py`, `models/` 를 고치면
  로컬은 서버 재시작, Streamlit Cloud 는 Reboot(또는 새 커밋 push)이 필요합니다.
  이걸 모르고 "안 바뀌는데?" 로 시간을 날리기 쉽습니다.
- **`AppTest.metric` 은 페이지 전체의 metric 을 돌려줍니다.** 특정 섹션만 검사하려면
  그 섹션에만 있는 라벨로 단언하세요. (예: 메인 화면에도 "잔여현금" 이 있습니다)
- **한글 조사**: `won_short()` 결과는 항상 억/만/원 으로 끝나 받침이 있습니다 → 은/이 고정.
- **분배금 캐시 키에는 기간이 없습니다** (`us:div:{ticker}`). 화면의 최근 12개월 조회와
  백테스트의 수년치 조회가 **같은 캐시 한 칸**을 씁니다. 알파카 키만 기간이 들어갑니다.
- 캡처 이미지는 html2canvas 가 아니라 **캔버스에 직접 그립니다**
  (`components/table_capture/frontend/index.html`). 화면과 이미지 내용이 어긋나지 않게 같이 고치세요.
- 커스텀 컴포넌트는 빌드 단계가 없는 **순수 HTML/JS** 입니다. npm 을 찾지 마세요.

## 버전과 배포

- 사용자에게 보이는 변화가 있으면 `config.APP_VERSION` 을 올립니다. 화면 헤더에 표시됩니다.
- 새 파일(특히 `services/`, `components/` 하위)을 만들었으면 **git 에 반드시 포함**시킵니다.
  빠뜨리면 클라우드에서 `ModuleNotFoundError` 로 앱이 아예 안 켜집니다.
- `.streamlit/config.toml` 은 저장소에 올라가야 합니다(밝은 테마 고정 — 안 올리면 다크모드
  기기에서 글자가 안 보입니다). `.streamlit/secrets.toml` 은 **절대 올리지 않습니다**
  (알파카 API 키). 클라우드 키는 Streamlit Cloud 대시보드 Secrets 에 있습니다.
- 새 서드파티 패키지를 쓰면 `requirements.txt` 에 직접 적습니다. 다른 패키지에 딸려오는 것에
  얹혀 가면 그쪽이 의존성을 빼는 순간 앱이 안 켜집니다.

## 구조

```
app.py              화면 전체 (긴 파일, 여기만 핫리로드)
config.py           APP_VERSION, 상수
models/             Security, Portfolio, 숫자 방어(numbers.py)
services/           계산·백테스트·달력·겹침·공유 등 순수 로직 (테스트는 주로 여기)
data/providers/     시세·환율·분배금 조회 + TTL 캐시(cache.py)
components/         전술판·매수입력·캡처·로컬저장 (순수 HTML/JS)
tests/              pytest
```
